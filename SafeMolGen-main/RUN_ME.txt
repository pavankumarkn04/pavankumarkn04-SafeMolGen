WHAT EACH FILE DOES
═══════════════════════════════════════════════════════════════════════════

run_demo.py
  - Tests if models load correctly
  - Generates 5 sample molecules
  - Shows molecular properties
  - OUTPUT ONLY IN CONSOLE (best for debugging)

backend/main.py
  - FastAPI server that runs the API
  - Handles /api/v1/* endpoints
  - Needs to be started with uvicorn command
  - OUTPUT: http://127.0.0.1:8000/docs (web interface)


IF SOMETHING IS WRONG
═══════════════════════════════════════════════════════════════════════════

1. Missing models?
   Check: checkpoints/generator/ has model.pt and tokenizer.json
   
2. Python error?
   Run: python --version (should be 3.11)
   
3. Module not found?
   Run: pip install -r requirements.txt
   
4. Still not working?
   The .venv might need to be recreated - check with your friend
